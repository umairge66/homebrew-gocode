# Homebrew tap for gocode

[gocode](https://github.com/umairge66/gocode) is an agentic coding assistant for your terminal, written in Go.

```sh
brew install umairge66/gocode/gocode
```

Update with `brew upgrade gocode`. Works on macOS and Linux (Intel and ARM).
The formula installs the signed release builds from
[gocode's releases](https://github.com/umairge66/gocode/releases).
